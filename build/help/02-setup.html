Your workbench

The tools you will use are on the right. They all share the same files, so a file you make in the terminal can be opened in a notebook straight away. It is worth spending ten minutes on this page before you start Part 1.

The tabs

NotebookWrite and run Python and R code in cells, with plots and tables. Most of your analysis and figures will be done here.
TerminalA Linux command line with standard genomics programs (samtools, bcftools, bedtools and seqtk), running in your browser.
FilesYour home folder and the read-only project data, with viewers for tables, sequences and text, and an editor.
DatabasesLive searches of Ensembl, NCBI and other databases. You will use it to check genes and variants.
Genome browserIGV, for looking at your variants, E-boxes and conservation scores along the genome (how to use it).
AIAn optional AI assistant. Read the rules below before you use it.

Where your files are

Your own work goes in your home folder, ~. The project data is in /data/examples, which is read-only. Have a look:

ls -R /data/examples

You should see folders called genes, reference, variants, conservation and motif. Every file is described in The project data. This shows the first few lines of the channelopathy gene list:

column -t -s$'\t' /data/examples/genes/brain_channelopathy.tsv | head

Three quick exercises

Terminal. Use samtools to pull one promoter's sequence out of the reference, then find its length. The second command drops the header line, joins the sequence lines together and counts the letters:

samtools faidx /data/examples/reference/promoters.fa SCN1A | head -3
samtools faidx /data/examples/reference/promoters.fa SCN1A | grep -v ">" | tr -d "\n" | wc -c

Notebook (Python). In a Python notebook, read the gene list into a table:

import pandas as pd
genes = pd.read_csv("/data/examples/genes/epilepsy_all.tsv", sep="\t")
print(genes.shape)
genes.head()

Genome browser. Go to the start of SCN1A to see a promoter in its place on the genome. The green bar is the promoter window, the short marks below it are 1000 Genomes variants, and the track below those shows conservation. The genome browser needs an internet connection and can take a few seconds to load the first time.

Saving your work

Everything you do is saved automatically, but only in this browser on this computer. Nothing is stored on a server, and nobody else can see it. To hand work in or move it to another computer, use Download in the Notebook tab to save a notebook as an .ipynb file, or My files (top right) to download everything as a .zip file. On a shared computer, download your work before you leave.

If you use the AI assistant
  1. Never put personal or patient data into the AI tab. This project uses only public reference data.
  2. You are responsible for your results. An AI can be wrong while sounding confident. For anything you report, you need to be able to point to the command you ran and the output it gave.
  3. Use it to help you understand, not to skip the work. Ask it to explain an error or a line of code. If it writes code for you, read every line before you run it.
