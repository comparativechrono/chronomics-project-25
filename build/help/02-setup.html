Where things live

Your own work goes in your home folder, ~. The project data is read-only in /data/examples. Have a look:

ls -R /data/examples

You should see folders for genes, reference, variants, conservation and motif. The project data describes every file. Peek at the channelopathy gene list:

column -t -s$'\t' /data/examples/genes/brain_channelopathy.tsv | head

Keep your work

Everything you do is saved in this browser on this computer automatically. It is not on a server and nobody else can see it. To hand work in or move it: Download in the Notebook tab saves a notebook as .ipynb; My files (top right) downloads everything as a .zip. On a shared computer, download before you leave.

If you use the AI assistant — three rules
  1. No personal or patient data in the AI tab, ever. Public reference data only — which is all this project uses.
  2. The result is yours. An AI can be wrong and sound sure. Whatever you report, you must be able to point to the command and the output it came from.
  3. Use it to understand, not to skip. Ask it to explain an error or a line of code. If it writes code for you, read every line and run it yourself.
