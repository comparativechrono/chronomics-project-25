The gene lists

Before you can look for E-boxes, you need to know which genes to look at, and exactly where each one starts. Part 1 sets that up.

Where the lists come from

Deciding which genes "cause" a disease is a job for experts, and Genomics England's PanelApp does exactly that: panels of genes rated by evidence, where green means well established (). We took the green genes from two panels and saved them for you:

  • /data/examples/genes/brain_channelopathy.tsv — 21 genes, your close-focus set.
  • /data/examples/genes/epilepsy_all.tsv — 632 genes, your statistics set (it includes the 21).

Read a gene list

Open a Python notebook and load both lists:

import pandas as pd
chan = pd.read_csv("/data/examples/genes/brain_channelopathy.tsv", sep="\t")
epi  = pd.read_csv("/data/examples/genes/epilepsy_all.tsv", sep="\t")
print("channelopathy genes:", len(chan))
print("epilepsy genes:", len(epi))
chan

Each row has the gene symbol, its Ensembl identifier, the chromosome and strand, the TSS (transcription start site), and the promoter window we will use. The strand matters: a gene on the - strand is read right-to-left along the chromosome, so its promoter is on the higher-coordinate side of the TSS. The file has already taken care of that.

Look at the spread

A quick plot — which chromosomes are these genes on?

import matplotlib.pyplot as plt
counts = epi["chrom"].value_counts()
counts.plot(kind="bar", figsize=(9,3))
plt.ylabel("genes"); plt.title("Epilepsy-panel genes by chromosome"); plt.tight_layout()

Check one gene against the live database

It is good practice to confirm a file against its source. Use the Databases tab to look up SCN1A in Ensembl, and check the chromosome and strand match the table.

Think about

The channelopathy set has 21 genes; the epilepsy set has 632. Why keep both? When you later ask "are E-boxes more common than chance?", which set gives you a more trustworthy answer, and why? (Hint: how many E-boxes would you expect to even see in 21 short promoters?)
