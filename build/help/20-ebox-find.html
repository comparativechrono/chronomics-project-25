Find the E-boxes

The canonical clock E-box is the six bases CACGTG. The first task is to find every copy of it in the promoters and record where each one is on the genome.

CACGTG reads the same on both strands

CACGTG is a palindrome: its reverse complement (swap C with G and A with T, then read it backwards) is the same sequence. DNA has two strands, but because the motif is palindromic, searching one strand finds every copy on both. That keeps the code simple.

Scan every promoter

In a Python notebook, run the code below. It reads the promoter FASTA file, finds every CACGTG, and converts the position of each hit within the promoter into a position on the chromosome, using the genomic start stored in the FASTA header:

import re

def read_fasta(path):
    name, seq, out = None, [], []
    for line in open(path):
        if line.startswith(">"):
            if name: out.append((name, "".join(seq)))
            name, seq = line[1:].strip(), []
        else:
            seq.append(line.strip().upper())
    if name: out.append((name, "".join(seq)))
    return out

records = read_fasta("/data/examples/reference/promoters.fa")

eboxes = []
for header, seq in records:
    gene = header.split()[0]
    region = header.split()[1]            # e.g. chr2:166127520-166129020
    chrom = region.split(":")[0]
    gstart = int(region.split(":")[1].split("-")[0])   # 1-based genomic start of the window
    for m in re.finditer("(?=CACGTG)", seq):           # (?=...) finds overlapping hits too
        off = m.start()
        eboxes.append((chrom, gstart + off - 1, gstart + off + 5, gene))  # BED: 0-based start

print("canonical E-boxes found:", len(eboxes))

Save them as a BED file

Write the hits to a file in your home folder, so that you can use them in the terminal and the genome browser:

with open("/home/user/eboxes_canonical.bed", "w") as f:
    for chrom, s, e, gene in eboxes:
        f.write(f"{chrom}\t{s}\t{e}\t{gene}|CACGTG\t0\t+\n")
print("wrote /home/user/eboxes_canonical.bed")

Now look at the channelopathy genes

How many of those E-boxes are in your 21 channelopathy genes? Load the gene list and check:

import pandas as pd
chan = set(pd.read_csv("/data/examples/genes/brain_channelopathy.tsv", sep="\t")["gene"])
in_chan = [e for e in eboxes if e[3] in chan]
print("canonical E-boxes in the 21 channelopathy genes:", len(in_chan))
Checkpoint

You should find 205 canonical E-boxes across the 641 promoters, but none in the 21 channelopathy genes. That may look odd, but it doesn't mean the clock ignores these genes. Searching for the exact string CACGTG is very strict, and many working binding sites differ from it by a base. In the next step you will search with a flexible motif model instead, which is how binding sites are usually found, and the channelopathy genes will show up.
