Are there more E-boxes than chance?

Finding 205 E-boxes tells you little until you know how many you would expect by chance. Working out that expectation properly is the most important part of this step.

CACGTG contains a CpG

The middle of CACGTG is the dinucleotide CG, known as a CpG. CpGs behave differently from other DNA: they are rarer in the genome than you would expect, and they mutate faster than other sites. The simple expectation (four bases, each with a one in four chance, so CACGTG should turn up once in every 4⁶ positions) takes no account of either. You need to compare against a background that reflects these promoters' base composition and their dinucleotide composition.

A fair expectation

Fit a simple model to the promoters themselves, which records how often each base is followed by each other base, and ask how many copies of CACGTG it predicts. Run this in Python (it reuses records):

from collections import Counter
pool = "".join(seq for _, seq in records)
base = Counter(c for c in pool if c in "ACGT"); N = sum(base.values())
di = Counter(pool[i:i+2] for i in range(len(pool)-1) if pool[i] in "ACGT" and pool[i+1] in "ACGT")

def P(a): return base[a]/N
def T(a,b):                                   # P(next=b | this=a)
    s = sum(di[a+x] for x in "ACGT"); return di[a+b]/s if s else 0.25

word = "CACGTG"
p_word = P(word[0])
for i in range(len(word)-1): p_word *= T(word[i], word[i+1])
positions = sum(max(0, len(seq)-5) for _, seq in records)
expected = p_word * positions
observed = len(eboxes)                         # from the find step
print(f"observed {observed} | expected ~{expected:.0f} | ratio {observed/expected:.2f}")
Checkpoint

You should see about 205 observed against ~123 expected, a ratio of about 1.66. Canonical E-boxes are roughly 1.7 times more common in these promoters than expected, even after allowing for CpG content, which is a sign that the clock pathway reaches these genes. (Try the same calculation for CACGTT, a related sequence that CLOCK:BMAL1 binds only weakly. Is it enriched?)

Why the baseline matters

With the simple 1 in 4⁶ expectation you would have reported a much larger enrichment, and a reviewer would rightly have rejected it, because CpG content alone could explain it. A fair baseline is what separates a finding from an artefact. Write down in your notes which baseline you used and why.
