Variants that hit an E-box

You have E-boxes (positions on the genome) and variants (other positions on the genome). The question is simple: which variants land inside an E-box? That is a job for bedtools.

Intersect, the standard way

bedtools intersect finds overlaps between two sets of genomic regions. Overlap your canonical E-boxes with the variants:

cd ~
bedtools intersect -a eboxes_canonical.bed -b /data/examples/variants/promoter_variants.vcf.gz -wa -wb \
  | head
# count the variants that fall in a canonical E-box:
bedtools intersect -a eboxes_canonical.bed -b /data/examples/variants/promoter_variants.vcf.gz -wb \
  | wc -l
In a canonical E-box, every variant breaks it

CACGTG is the best sequence. Any single-letter change inside it makes it something else, so every SNV that lands in a canonical E-box weakens or destroys the switch (you can confirm this with the PWM score in the next step). Occasionally a variant does the opposite — it turns a near-miss into a perfect CACGTG, creating a switch. Both are interesting.

Build your catalogue in Python

Join the variants table (var, from the last step) to your E-boxes so each E-box variant carries its gene and its population frequencies. One clean way: mark every genomic position that is inside a canonical E-box, then select variants at those positions:

ebox_pos = set()
for chrom, s, e, gene in eboxes:          # from the find step (BED: 0-based s, end e)
    for p in range(s+1, e+1):             # 1-based genomic positions
        ebox_pos.add((chrom, p))

var["in_ebox"] = [ (c,p) in ebox_pos for c,p in zip(var.chrom, var.pos) ]
catalogue = var[var.in_ebox].copy()
print("variants inside a canonical E-box:", len(catalogue))
catalogue.sort_values("AF", ascending=False).head(10)

Look at the population columns

For each catalogue variant, compare AF_AFR … AF_SAS. Are any common in one group and rare in another? A variant that breaks a clock switch but is common somewhere is especially worth a look.

cols = ["gene","pos","ref","alt","AF","AF_AFR","AF_AMR","AF_EAS","AF_EUR","AF_SAS"]
catalogue[cols].sort_values("AF", ascending=False).head(12)
Checkpoint

About 27 variants fall inside a canonical E-box. Most are rare — which is exactly what you would expect if breaking the switch is usually mildly harmful and selection keeps such variants down.
