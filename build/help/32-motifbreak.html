Scoring the damage a variant does

"Inside an E-box" is yes/no. Better is how much a variant changes the switch. Score the sequence with the reference letter, score it again with the variant's letter, and take the difference. This is exactly how published tools (like motifbreakR) work — and you can do it in a few lines.

The idea

For a variant, slide the BMAL1 matrix across the DNA around it. In each window, compute the relative score with the reference letter and with the alternative letter. The window where the motif is strongest is the one that matters; the change in score (alt − ref) tells you whether the variant weakens the switch (negative), strengthens it, or does nothing.

Compute it

This reuses w, relscore, best_both and L from the PWM step, and var from the variants step. First index the promoter sequences by gene:

gene_seq = {}
for header, seq in records:
    gene  = header.split()[0]
    chrom = header.split()[1].split(":")[0]
    gstart= int(header.split()[1].split(":")[1].split("-")[0])
    gene_seq[gene] = (chrom, gstart, seq)

def motif_effect(gene, pos, ref, alt):
    chrom, gstart, seq = gene_seq[gene]
    off = pos - gstart                       # 0-based index into the promoter sequence
    if off < 0 or off >= len(seq) or seq[off] != ref:
        return None                          # variant not in this window / reference mismatch
    best = None
    for wst in range(max(0, off-L+1), min(off, len(seq)-L)+1):
        ref_w = seq[wst:wst+L]
        alt_w = ref_w[:off-wst] + alt + ref_w[off-wst+1:]
        rr, ra = best_both(ref_w), best_both(alt_w)
        if best is None or max(rr,ra) > max(best[0],best[1]):
            best = (rr, ra)
    rr, ra = best
    return round(rr,3), round(ra,3), round(ra-rr,3)

Apply it to every variant and classify each one (threshold 0.85, as before):

THR = 0.85
rows = []
for r in var.itertuples():
    eff = motif_effect(r.gene, r.pos, r.ref, r.alt)
    if not eff: continue
    rr, ra, d = eff
    if   rr>=THR and ra< THR: cls="break"
    elif rr< THR and ra>=THR: cls="create"
    elif rr>=THR and ra>=THR: cls="weaken" if d<0 else "strengthen"
    else: cls="none"
    if cls!="none":
        rows.append((r.gene, r.chrom, r.pos, r.ref, r.alt, r.AF, rr, ra, d, cls))

import pandas as pd
eff = pd.DataFrame(rows, columns=["gene","chrom","pos","ref","alt","AF","pwm_ref","pwm_alt","delta","class"])
print(eff["class"].value_counts())
eff.sort_values("delta").head(10)        # the biggest disruptions
Checkpoint

You should find on the order of 169 variants that break a strong site and 160 that create one, plus many that weaken or strengthen. This is a far richer catalogue than the exact-match one, and it reaches the channelopathy genes. These "break" variants — especially in channelopathy genes — are your candidate list for Part 5.

A caution

A score change is a prediction, not proof the switch is really used in the brain. CLOCK:BMAL1 may not even bind this particular site in neurons. That is why the next step — is the position conserved and depleted of variation? — adds independent evidence, and why the real test is in patients.
