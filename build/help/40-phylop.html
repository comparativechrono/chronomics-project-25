Conservation

If an E-box is an important control site, damaging it would have been harmful to our ancestors as well, so evolution should have kept its sequence the same across species. A conservation score measures this.

What phyloP is

phyloP compares the same position across the genomes of many species and asks whether it has changed less than neutral DNA (it is conserved, and gets a positive score) or more (it is evolving quickly, and gets a negative score) (). We use the 470-way mammalian alignment from the Zoonomia project, currently one of the best resources for finding constrained regulatory DNA (). A score above about 2 means a position has changed unusually little across mammals.

We saved the phyloP score for every base of every promoter, so you don't need to download the very large genome-wide file:

zcat /data/examples/conservation/phylop_promoters.csv.gz | head -3

Conservation at an E-box

Load the table and look at the scores for the six positions of one of your canonical E-boxes:

import pandas as pd
phylop = pd.read_csv("/data/examples/conservation/phylop_promoters.csv.gz")
# a few promoters overlap (two genes that start close together), so some positions are listed twice: keep each once
phylop = phylop.drop_duplicates(["chrom","pos"]).set_index(["chrom","pos"]).sort_index()

chrom, s, e, gene = eboxes[0]          # first E-box (BED: 0-based s)
for p in range(s+1, e+1):
    print(p, gene, phylop.loc[(chrom, p), "phyloP470"])

Are those six numbers high (conserved) or low? Try a few more E-boxes, then a few random promoter positions, to get a feel for the difference before you measure it properly in the next step.

Why conservation helps

The PWM score from Part 3 is a prediction based on a matrix measured in the lab. phyloP is independent evidence from evolution: it knows nothing about CLOCK:BMAL1, only which positions have stayed the same over millions of years. If a predicted site is also highly conserved, the case that it is a working site is much stronger.
