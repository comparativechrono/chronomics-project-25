The selection test

This is the central test of the project. If E-boxes are working control sites that selection keeps intact, then compared with fair control positions they should be more conserved and carry fewer, rarer variants. On this page you measure both.

Choosing a fair control

You can't simply compare E-boxes with all promoter DNA, because CACGTG contains a CpG, and CpGs behave differently from ordinary DNA: they mutate faster, and near promoters they are often conserved themselves. The fair comparison is between E-box positions and other CpG positions in the same promoters. Any difference you then see is down to the E-box, not to CpGs in general.

Label every position

Label each promoter base as ebox, cpg_control (a CpG that is not in an E-box) or other, and add its phyloP score and whether a variant was seen there. Run this in Python (it reuses records, eboxes, var and the phylop table):

import pandas as pd, numpy as np
ebox_pos = set()
for chrom, s, e, gene in eboxes:
    for p in range(s+1, e+1): ebox_pos.add((chrom, p))
var_pos = {(c,p): af for c,p,af in zip(var.chrom, var.pos, var.AF)}

rows = []
for header, seq in records:
    chrom  = header.split()[1].split(":")[0]
    gstart = int(header.split()[1].split(":")[1].split("-")[0])
    for i in range(len(seq)-1):
        pos = gstart + i
        is_cpg  = seq[i]=="C" and seq[i+1]=="G"
        is_ebox = (chrom,pos) in ebox_pos
        cls = "ebox" if is_ebox else ("cpg_control" if is_cpg else "other")
        rows.append((chrom, pos, cls, (chrom,pos) in var_pos))
pos_df = pd.DataFrame(rows, columns=["chrom","pos","cls","variant"])
pos_df = pos_df.merge(phylop.reset_index(), on=["chrom","pos"], how="left")
pos_df["cls"].value_counts()

Is the difference real?

Compare the phyloP scores of E-box positions and CpG-control positions with a Mann–Whitney U test, which doesn't assume the scores are normally distributed:

from scipy.stats import mannwhitneyu
a = pos_df.loc[pos_df.cls=="ebox", "phyloP470"].dropna()
b = pos_df.loc[pos_df.cls=="cpg_control", "phyloP470"].dropna()
U, p = mannwhitneyu(a, b, alternative="greater")
print(f"E-box median {a.median():.2f} vs CpG-control {b.median():.2f};  p = {p:.1e}")
Checkpoint

E-box positions should be much more conserved than control CpGs: a mean phyloP470 of about 2.7, against about −0.2 for the controls, with the "other" promoter positions in between at about 0.9. The Mann–Whitney test gives p < 1e-100. E-boxes also carry about half as many variants per base as control CpGs (about 22 against 43 per 1000 bp). Both results point the same way, to purifying selection keeping these sites intact, and this is your main finding.

Confounding

E-boxes near a TSS might be conserved because that part of the promoter is conserved, rather than because they are E-boxes. The CpG control helps, but note this limitation in your write-up. A stronger follow-up (one of the extensions in Part 5) is to check whether the conserved E-boxes with little variation are also the ones with the highest PWM scores, which would mean that the strength of a site predicts how constrained it is.
