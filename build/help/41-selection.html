The selection test

This is the heart of the project. If E-boxes are functional switches kept intact by selection, then compared with fair control positions they should be more conserved and carry fewer, rarer variants. Here you measure both — carefully.

Choosing a fair control

You cannot compare E-boxes with "all promoter DNA", because CACGTG contains a CpG, and CpGs behave differently from ordinary DNA (they mutate faster and are themselves often conserved near promoters). The fair comparison is E-box positions versus other CpG positions in the same promoters. Then any difference you see is about the E-box, not about CpGs in general.

Tag every position

Mark each promoter base as ebox, cpg_control (a CpG not in an E-box), or other, and attach its phyloP score and whether a variant was seen there. Run in Python (reuses records, eboxes, var, and the phylop table):

import pandas as pd, numpy as np
ebox_pos = set()
for chrom, s, e, gene in eboxes:
    for p in range(s+1, e+1): ebox_pos.add((chrom, p))
var_pos = {(c,p): af for c,p,af in zip(var.chrom, var.pos, var.AF)}

rows = []
for header, seq in records:
    chrom  = header.split()[1].split(":")[0]
    gstart = int(header.split()[1].split(":")[1].split("-")[0])
    for i in range(len(seq)-1):
        pos = gstart + i
        is_cpg  = seq[i]=="C" and seq[i+1]=="G"
        is_ebox = (chrom,pos) in ebox_pos
        cls = "ebox" if is_ebox else ("cpg_control" if is_cpg else "other")
        rows.append((chrom, pos, cls, (chrom,pos) in var_pos))
pos_df = pd.DataFrame(rows, columns=["chrom","pos","cls","variant"])
pos_df = pos_df.merge(phylop.reset_index(), on=["chrom","pos"], how="left")
pos_df["cls"].value_counts()

Result 1 — conservation

pos_df.groupby("cls")["phyloP470"].mean()

Result 2 — how much variation

(pos_df.groupby("cls")["variant"].mean()*1000).round(2)   # segregating SNVs per 1000 bp

Is the difference real? A statistical test

Compare the phyloP of E-box positions with CpG-control positions using a Mann–Whitney U test (it doesn't assume a bell-curve):

from scipy.stats import mannwhitneyu
a = pos_df.loc[pos_df.cls=="ebox", "phyloP470"].dropna()
b = pos_df.loc[pos_df.cls=="cpg_control", "phyloP470"].dropna()
U, p = mannwhitneyu(a, b, alternative="greater")
print(f"E-box median {a.median():.2f} vs CpG-control {b.median():.2f};  p = {p:.1e}")
Checkpoint — the result

You should find E-box positions are much more conserved (mean phyloP470 ≈ 2.7) than control CpGs (≈ −0.2; the "other" promoter positions sit in between, ≈ 0.9); the Mann–Whitney test gives p < 1e-100. And E-boxes carry about half the variants per base of control CpGs (≈ 22 vs ≈ 43 per 1000 bp). Both point the same way: purifying selection has been keeping these switches intact. That is your main finding.

Be honest about the confounds

E-boxes near a TSS could be conserved because that part of the promoter is conserved, not because it is an E-box. Your CpG-control helps, but write down this limitation. A stronger follow-up (Part 5) is to check whether the conserved, variation-depleted E-boxes are also the ones with the highest PWM scores — function predicting constraint.
