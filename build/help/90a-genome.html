The genome browser

The Genome browser tab is IGV (), showing the human reference genome GRCh38 (hg38) — the same build as all the project data. The genome comes from the IGV team's servers, so this tab needs the internet.

What you see

Above the genome's own gene track (Refseq All, at the bottom), three tracks of this project are shown:

Project promoters (TSS −1000/+500)The 641 promoter windows, from /data/examples/genes/promoters.bed. Click a box for its gene.
1000 Genomes promoter SNVsEvery promoter variant, from /data/examples/variants/promoter_variants.vcf.gz. Click a variant for its allele frequencies (AF, AF_EUR …).
phyloP 470-way (mammals)Conservation at every base: bars above the line mark positions held still across mammals, bars below it fast-changing ones. It is read, a piece at a time, from UCSC's copy of the genome-wide file — the same scores as conservation/phylop_promoters.csv.gz.

Go somewhere

Type a gene (SCN1A) or a position (chr2:166,127,520-166,129,020) in the box at the top of the browser and press Enter. Drag sideways to move, and use + and − to zoom: close in, the letters of the sequence appear. For example:

Add your own tracks

Files you make — your E-boxes, your catalogue as a BED file — can be shown as tracks too. In the Genome browser tab, Add my files… lists the BED, VCF and bedGraph files in your home folder; or use the button below once you have made eboxes_canonical.bed in Find the E-boxes. Their chromosome names must be written as here (chr2, not 2) and their positions must be GRCh38.

Keep a picture

Save image downloads the current view as a PNG file — useful for your report (say which region it shows).

If it does not start

The genome and the conservation track come over the internet. If the tab says the genome browser could not start, check your connection and press Try again, or reload the page. The rest of the workbench works without it.
