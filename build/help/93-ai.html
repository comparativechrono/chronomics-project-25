Using the AI assistant

The AI tab is optional. Used well, it is a patient tutor that never tires of your questions. Used badly, it writes code you don't understand and sometimes invent facts. Here is how to get the good version.

What it is good for

  • Explaining an error. Paste the red error message and ask what it means.
  • Explaining a line of code in this guide you don't follow.
  • Translating between Python and R, or suggesting a plot.
  • Unsticking you when you know what you want but not the command.

The rules (again, because they matter)

  1. No personal or patient data in the AI tab. This project is public data only — fine.
  2. You own the result. If the AI gives you a number or a conclusion, do not report it until you have produced it yourself from the data and can point to the command.
  3. Read every line it writes and run it yourself. If you can't explain what a line does, ask it to explain, or don't use it.
  4. A key is a password. You connect your own model with an API key; it stays in this browser tab only. Don't share it.
A good habit

When the AI writes code, ask it a follow-up: "what would break this?" or "what am I assuming here?". The goal of this project is that you can do regulatory genomics — the assistant is there to help you learn it, not to do it instead of you.
