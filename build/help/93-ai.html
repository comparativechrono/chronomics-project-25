Using the AI assistant

The AI tab is optional. It can be a useful tutor, explaining an error or a piece of code as many times as you need. But it can also write code you don't understand, and it sometimes makes things up, so use it with care.

What it is good for

  • Explaining an error. Paste in the red error message and ask what it means.
  • Explaining a line of code in this guide that you don't follow.
  • Translating between Python and R, or suggesting a plot.
  • Getting unstuck when you know what you want to do but not which command does it.

The rules

  1. Never put personal or patient data into the AI tab. This project uses only public data, so that shouldn't come up.
  2. You are responsible for the result. If the AI gives you a number or a conclusion, don't report it until you have produced it yourself from the data and can point to the command you used.
  3. Read every line of code it writes, and run it yourself. If you can't explain what a line does, ask it to explain, or don't use it.
  4. Treat your API key like a password. You connect your own AI model with an API key, which is kept only in this browser tab. Don't share it.
A good habit

When the AI writes code for you, ask a follow-up question such as "what could make this go wrong?" or "what am I assuming here?". The aim of this project is for you to learn to do regulatory genomics. The assistant is there to help you learn, not to do the work for you.
