Glossary

Plain-language definitions of the words this project uses. Search the guide (top left) to jump to where each one is used.

Allele frequency (AF)
The fraction of chromosomes in a group that carry a particular variant letter. Low = rare, high = common.
BED file
A plain-text list of genomic regions (chromosome, start, end). Counts from 0; the end is one past the last base.
BMAL1 / CLOCK
The two proteins that join and switch on clock-controlled genes by binding E-boxes.
Channelopathy
A disease caused by a faulty ion channel — many epilepsies are channelopathies.
Conservation
How little a DNA position has changed across species. Measured here by phyloP; high = constrained.
CpG
A C followed by a G. CpGs mutate faster than other DNA and behave specially — which is why they need a fair control.
E-box
The DNA switch CLOCK:BMAL1 binds. The canonical one is the palindrome CACGTG.
Enrichment
Finding something more often than a fair "by chance" expectation would predict.
FASTA
A text format for DNA/protein sequence: a > header line, then the letters.
GRCh38
The current human reference genome build. All coordinates here are GRCh38.
phyloP
A per-position conservation score from comparing many species; positive = conserved, negative = fast-changing.
Promoter
The DNA just before a gene's start where its switches (including E-boxes) sit.
Purifying selection
Evolution removing harmful changes, leaving important positions conserved and depleted of variation.
PWM (position weight matrix)
A flexible description of what sequence a protein binds, scored from 0 to 1, that allows near-misses.
SNV
A single-nucleotide variant: one DNA letter changed.
TSS
Transcription start site: where a gene begins to be copied into RNA.
VCF
The standard file format for variants: position, reference letter, alternative letter, and information fields.
